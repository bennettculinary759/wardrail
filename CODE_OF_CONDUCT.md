# Code of conduct

Wardrail welcomes people with different experience levels, including
first-time open-source contributors and developers who began through
vibecoding.

## Expected behavior

- Be respectful, patient, and specific.
- Critique code and ideas, not people or their experience level.
- Help contributors remove secrets and private data from reports.
- Give actionable feedback and explain unfamiliar security concepts.
- Assume good intent while protecting users from unsafe changes.

## Unacceptable behavior

- Harassment, discrimination, intimidation, or personal attacks.
- Publishing another person's private information or credentials.
- Mocking beginners for security mistakes.
- Deliberately introducing unsafe examples that contain working secrets.
- Disrupting project spaces or contributor work.

## Enforcement

Repository maintainers may edit, remove, or reject contributions and
interactions that violate these expectations. Serious security concerns
should follow `SECURITY.md` instead of being posted publicly.
